# Mobile Upload Guide

Use this guide only for the initial repository population.

1. Download `EDGE_GITHUB_READY.zip` to your phone.
2. Extract the ZIP using your phone's Files app.
3. Open GitHub in your mobile browser and sign in.
4. Open repository `EDGE---V1`.
5. Open the repository in Desktop Site mode if the mobile page hides upload controls.
6. Upload files/folders from the extracted package to the repository root.
7. Commit with message: `Initialize EDGE V1 technical repository`.
8. Verify these top-level items exist:
   - README.md
   - .gitignore
   - config/
   - docs/
   - migrations/
   - schema/
   - src/
   - tests/
9. Switch the repository back to Private after upload.
10. Do not upload `.env`, passwords, connection strings, tokens, or credentials.
